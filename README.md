# Haiduc-Auto: programări școală de șoferi

## Cerințe
- Git, Node.js LTS, VS Code

## Pornire
1. git clone <URL-ul repo-ului>
2. Frontend:
   cd client
   npm install
   copiază .env.example în .env.local și completează cheile
   npm run dev
3. Backend:
   cd server
   npm install
   copiază .env.example în .env și completează cheile
   node index.js

## Reguli
- Cheile (.env) nu se pun niciodată pe GitHub
- Fiecare lucrează pe branch propriu
- Mesaj clar la fiecare commit
